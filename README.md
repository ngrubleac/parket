# Реставрация Паркета — MasterParchet

Профессиональный веб-сайт для бизнеса по реставрации, циклевке и шлифовке паркета в Кишиневе и по всей Молдове.

## 🚀 Стек Технологий

- **Фреймворк:** [Astro v4](https://astro.build/) (Hybrid Rendering)
- **Frontend:** [React](https://reactjs.org/) + [Tailwind CSS](https://tailwindcss.com/)
- **Анимации:** [Framer Motion](https://www.framer.com/motion/)
- **CMS:** [Keystatic](https://keystatic.com/) (управление контентом и галереей)
- **Языки:** Мультиязычность (Русский, Румынский)
- **Деплой:** Оптимизировано для [Vercel](https://vercel.com/)

## ✨ Основные Функции

- **Интерактивный Hero-блок:** Эффект "прожектора" на главном баннере, раскрывающий цветной паркет при движении мыши.
- **Калькулятор Стоимости:** Интерактивный расчет стоимости работ в зависимости от площади и состояния паркета.
- **Галерея работ:** Просмотр проектов в формате "До/После".
- **Управление контентом:** Легкое обновление услуг и галереи через панель Keystatic.
- **Адаптивный дизайн:** Полная поддержка мобильных устройств и планшетов.

## 🛠 Запуск проекта

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Сайт будет доступен по адресу: `http://localhost:4321`
Панель управления Keystatic: `http://localhost:4321/keystatic`

### Сборка для продакшена
```bash
npm run build
```

## 📁 Структура проекта

- `src/components/` — React и Astro компоненты.
- `src/content/` — Контент сайта (услуги, галерея).
- `src/i18n/` — Конфигурация переводов (RU/RO).
- `src/pages/` — Страницы сайта.
- `public/` — Статические ресурсы (изображения, шрифты).
- `keystatic.config.tsx` — Конфигурация CMS.

## 🚢 Деплой

Проект настроен для деплоя на **Vercel**. При пуше в ветку `main` происходит автоматическая сборка и публикация.
